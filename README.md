# 🗂️ Projetos Hashtag

Este repositório reúne projetos de estudo e práticas desenvolvidas ao longo do curso Jornada Python da Hashtag Treinamentos, com foco em diferentes aplicações reais e comuns em desenvolvimento, automação, análise e ciência de dados.

## 📊 1. Análise de Dados

Este projeto é voltado ao tratamento, visualização e insights de dados.

### Funcionalidades e Utilidade:
- Importação de database.
- Limpeza e organização de dados.
- Análise exploratória para descobrir padrões.
- Geração de gráficos e relatórios com insights relevantes.
- Possíveis conclusões a partir das tendências encontradas.

Esse tipo de projeto é comumente usado para aprender a trabalhar com dados reais e apoiar decisões com base nas informações extraídas.

## 🤖 2. Automação de Cadastro

Este projeto é focado em automação de tarefas repetitivas, exemplificado com o cadastramento de produtos em um sistemas, mas também pode ser usado para automatizar planilhas e interfaces web. 

### Funcionalidades e Utilidade: 
- Sistema que reduz esforço manual no registro de informações.
- Organização de dados para entrada em sistemas.
- Útil em cenários corporativos para reduzir retrabalho e erros manuais.

## 🧠 3. Machine Learn

Esse projeto está relacionado a Machine Learning, ou seja, ao desenvolvimento de modelos capazes de aprender padrões a partir de dados.

### Funcionalidades e Utilidade:
- Pré-processamento de dados para modelos.
- Treinamento e avaliação de algoritmos de aprendizado.
- Visualizações de performance e análise de métricas.
- Essenciais para transformar dados em previsões ou decisões automatizadas.

## 🛠️ Tecnologia e Estruturas Utilizadas

Os projetos deste repositório fazem uso de:

- Python
- Jupyter Notebook
- Bibliotecas Python:
    - Análise de Dados:
        - Pandas
        - Plotly
    - Automação de Cadastro:
        - Pyautogui

    - Machine Learn:
